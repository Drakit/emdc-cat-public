# EMDC-LD01 V2.0 RC2
Candidato independiente. V1.0 y RC1 se conservan.
- LD-M12–M14: botón directo, barra inferior y limpieza de selección; máximo cuatro.
- LD-M15: fotografías exclusivamente de una proyección pública aprobada, alojadas bajo assets del mismo sitio y marcadas como autorizadas. No se han publicado fotografías reales.
- LD-M16–M17: detalle por registro y enlace de ficha explícito al blog EMDC; no se inventa enlace ni se confunde con fuente documental.
- LD-M18–M20: acceso a filtros, nivel visible, etiquetas de filtros removibles.
- Paleta tomada del XML de referencia MES-01 V1.8: fondo #444444, publicación #1d1d1d, menú #273744, hover #344e63, acento #ff9800. Roboto/Arial. No se altera Blogger ni se duplica textura.
- Motor: cache de campos presentes por nivel, filtros dependientes sin ordenación redundante, proyección por niveles, campos UNI autorizados por matriz y nivel; listas escalares y objetos de medida con campos permitidos. No activar perfiles candidatos.
- El manifiesto selecciona exclusivamente demo.json o una futura public-data.json aprobada. No se publicó la base real. No hay servicio de autenticación ni backend. La marca APPROVED es un contrato de datos, no una autorización criptográfica.
- El importador local acepta CAT V3.4 y UNI T03, sin escribir la base; no sustituye FT02. No verifica el paquete UNI completo ni firmas. Para datos privados sensibles, utilizar una copia local de confianza.
## Integración
El archivo blogger-embed.txt contiene el componente de prueba. El tamaño y comportamiento de iframe deben comprobarse en una página autorizada. La publicación definitiva requiere validación.
